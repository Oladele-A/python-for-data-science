# Python for Data Science

This repository is a collection of Python exercises, Jupyter notebooks, and experiments documenting my continuous learning in **data analysis, optimisation, and machine learning.**

My objective is to develop the programming and quantitative skills required to analyse complex datasets, build computational models, and solve real-world problems, particularly in the **energy and electricity markets.**

Beyond documenting my learning journey, this repository will serve as a personal knowledge base and reference library that I can revisit whenever I need to refresh concepts, revisit techniques, or reuse previously developed code.

## Topics Covered
- **Python Fundamentals**: Programming concepts, data structures, control flow, functions, and object-oriented programming.

- **Data Analysis**: Data cleaning, manipulation, exploration, and statistical analysis using NumPy and Pandas.

- **Data Visualization**: Data exploration and visual communication using Matplotlib and Seaborn.

- **Time-Series Analysis**: Time-series data manipulation, trend and seasonality analysis, forecasting, and predictive modelling.


- **Optimisation**: Mathematical programming, constrained optimisation (linear programming, mixed-integer programming, etc)

- **Machine Learning**: Data preprocessing, supervised and unsupervised learning, model development, and evaluation.
